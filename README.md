# AcessLab

Sistema web para gestão de empréstimos de equipamentos eletrônicos em laboratório acadêmico.

---

## 📌 Sobre o Projeto

O **AcessLab** é uma aplicação web desenvolvida em PHP com o objetivo de organizar, registrar e controlar o empréstimo de equipamentos eletrônicos dentro do ambiente de laboratório.

O projeto surgiu a partir da necessidade de restaurar a segurança e a rastreabilidade no uso de equipamentos, após a interrupção dos empréstimos devido à falta de controle formal.

---

## 🎯 Objetivo

Desenvolver um sistema simples, funcional e organizado que permita:

- Cadastro de usuários
- Cadastro de equipamentos
- Registro de empréstimos
- Registro de devoluções
- Controle de status dos equipamentos
- Histórico de movimentações
